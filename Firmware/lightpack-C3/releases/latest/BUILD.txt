lightpack-C3 USB update channel
===============================

firmware:      0.5.0-dev
source:        usb-ota (first build with the USB UPDATE protocol)
built:         2026-11-14T01:18:53-03:00
firmware.bin:  1,282,704 bytes
sha256:        3B5B3FE957FC5576CF3202440B316360FC9831EA89C855BD018819FF4EEA4DE7
base:          boot_app0.bin (for ESP Web Tools compatibility; the console sends
               only firmware.bin to the inactive OTA slot)

The console verifies firmware.bin against the manifest SHA-256, sends it as
base64 chunks with UPDATE BEGIN/DATA/END, and the board writes it through
Update.h. NVS is untouched; the running image stays valid until END.

The first firmware with this protocol must be installed over USB once with
`pio run -e C3-USB -t upload` (or the browser installer). After that the console
can update itself.
