lightpack-C3 USB update channel
===============================

source commit: 934a3fa
built:         2026-11-14T00:07:35-03:00
firmware:      firmware.bin
base:          boot_app0.bin

This folder is the "latest build" channel used by the USB console's firmware
update button. It is replaced in place; it is not a tagged release. The app-only
firmware is written at 0x10000 and boot_app0.bin at 0xE000, which selects app0.
NVS (0x9000-0xE000) is not touched, so mode, palette, presets, networks and the
page login survive an update.

For a blank board or a full recovery, use the browser installer or a release
folder instead.
